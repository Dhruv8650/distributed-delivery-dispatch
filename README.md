# Distributed Delivery Dispatch Platform

A backend-focused distributed delivery dispatch and order assignment platform built using Java and Spring Boot.

## Objective

The system is designed to demonstrate:

- Microservices architecture
- API Gateway
- Event-driven communication using Apache Kafka
- Redis-based geospatial driver discovery
- Distributed locking for concurrent driver assignment
- Priority-based driver selection
- Idempotent event processing
- PostgreSQL database-per-service architecture
- Docker containerization
- Automated testing and CI/CD

## Services

- API Gateway
- Order Service
- Driver Service
- Dispatch Service
- Notification Service
